# Architecture

FreeDisplay is a SwiftUI `MenuBarExtra(.window)` app. Layers: **Views → Services → system frameworks** (CoreGraphics, IOKit, ColorSync, private CGVirtualDisplay / IOAVService / CoreDisplay / OSDUIHelper). `Models/` holds plain data. There is no separate ViewModel layer; a few views keep a small private view model inline (e.g. `SystemColorViewModel`).

## Layout

```
FreeDisplay/
├── App/            FreeDisplayApp (@main, creates DisplayManager, wires wake handler), AppDelegate (single instance, brightness keys, wake observer)
├── Models/         DisplayInfo (per-display @Published state), DisplayMode, DisplayPreset
├── Services/       All system interaction; @MainActor singletons (`static let shared`)
├── Views/          SwiftUI views; MenuBarView is the root container, DisplayDetailView the per-display panel
├── Utilities/      NSScreen extensions (displayID ↔ NSScreen)
└── FreeDisplay-Bridging-Header.h   Private API declarations (CGVirtualDisplay, IOAVService)
```

The project file is generated by XcodeGen from `project.yml`; every `.swift` file under `FreeDisplay/` is included automatically.

## Services

| Service | Responsibility |
|---|---|
| `DisplayManager` | Enumerates displays, handles hot-plug via `CGDisplayRegisterReconfigurationCallback`, auto-positions externals above the built-in screen |
| `DDCService` | DDC/CI over I2C: IOAVService (`DCPAVServiceProxy`) on Apple Silicon, IOFramebuffer I2C on Intel. 5 s VCP read cache, retries |
| `BrightnessService` | Unified brightness: built-in via IOKit, external via DDC (VCP 0x10), software fallback via `GammaService` |
| `GammaService` | **Sole writer** of `CGSetDisplayTransferByFormula/Table` (image adjustments + software brightness) |
| `AutoBrightnessService` | Follows built-in screen brightness (CoreDisplay via `dlsym`) and applies it to externals; 30 s cooldown after manual changes |
| `BrightnessKeyService` | `CGEvent` tap that routes brightness keys to the display under the cursor |
| `BrightnessHUDService` | Shows the native brightness OSD through the private `com.apple.OSDUIHelper` XPC service |
| `ResolutionService` | Switches display modes; reapplies saved mode after wake |
| `HiDPIService` | Writes `scale-resolutions` override plists to `/Library/Displays/Contents/Resources/Overrides/` (admin prompt via `NSAppleScript`) |
| `VirtualDisplayService` | Creates/destroys `CGVirtualDisplay` instances (runtime only, destroyed on quit) |
| `ArrangementService` | Reads/sets display positions and the main display |
| `ColorProfileService` | Lists and applies ICC profiles (ColorSync) |
| `NotchOverlayManager` | Black overlay window over the MacBook notch |
| `PresetService` | Saves/applies display presets (`~/Library/Application Support/FreeDisplay/presets.json`) |
| `SettingsService` | UserDefaults persistence; also hosts `AppLanguage`, `LanguageStore` and `L(_:_:)` |
| `LaunchService` | Launch at login via a per-user launchd agent in `~/Library/LaunchAgents` |
| `UpdateService` | Checks GitHub Releases for a newer version |
| `CGHelpers` | `runWithTimeout` — runs blocking WindowServer calls off the main thread with a timeout |
| `MirrorService` | Hardware mirroring via `CGConfigureDisplayMirrorOfDisplay` (currently not referenced by any view) |

## Key flows

```
Hot-plug:  CG reconfiguration callback → DisplayManager.refreshDisplays()
           → arrangeExternalAboveBuiltin() → @Published displays → views re-render

Wake:      NSWorkspace.didWakeNotification → AppDelegate.onWake (set in FreeDisplayApp)
           → BrightnessService.reapplySoftwareBrightnessIfNeeded   (must run first: provides the factor)
           → GammaService.reapplyIfNeeded
           → ResolutionService.reapplySavedModeIfNeeded

Brightness keys: CGEvent tap → BrightnessKeyService → BrightnessService (display under cursor)
                 → BrightnessHUDService (native OSD)
```

## Localization

UI strings are inline Turkish/English pairs: `L("Ayarlar", "Settings")`. `LanguageStore` is a hand-written `Observable`, so any view that calls `L` re-renders when the language changes. The choice is stored under `fd.language` (default: Turkish). Code, comments and docs are in English.

## High-risk files

| File | Why |
|---|---|
| `Models/DisplayInfo.swift` | Every view and service depends on it; grep all references when changing properties |
| `Services/DisplayManager.swift` | Global display list + hot-plug callback; test with plugging/unplugging |
| `Services/DDCService.swift` | Base of all external-display control; test on real hardware |
| `Services/GammaService.swift` | Shared gamma table owner; changes affect brightness and image adjustments |
| `Views/MenuBarView.swift` | Root container; check panel sizing on macOS 27 (it sizes to the content's minimum size) |
